화랑 WORKSPACE / CALCULATOR / ACADEMY · V63.3 전체 최적화본

이 ZIP은 최신 V63.3 개선 내용을 포함한 전체 소스입니다.
이전 V63.1 전체본이나 변경 파일 ZIP을 추가로 덮어쓸 필요가 없습니다.

1. 적용 순서
① 기존 저장소를 백업하거나 복구 가능한 커밋을 확보합니다.
② ZIP 전체를 저장소 루트의 같은 경로에 덮어씁니다.
   app.py / calculator_app.py / academy_app.py와 modules / hwarang_academy / assets / data가
   저장소 루트에서 바로 보여야 합니다. 별도 하위 폴더 안에 중첩하지 마세요.
③ 기존 저장소에 덮어쓴 경우, 프로젝트 루트에서 아래 명령으로 남은 불필요 파일을 확인합니다.
   python cleanup_obsolete_files.py
   확인 후 실제 정리를 하려면 다음 명령을 실행합니다.
   python cleanup_obsolete_files.py --apply
   새 빈 폴더에서 전체본을 사용하는 경우에는 정리할 예전 파일이 없습니다.
④ 새 SQL이 미적용이면 Supabase SQL Editor에서 아래 파일 전체를 실행합니다.
   supabase/migrations/18_NonBriefing_Training_History.sql
   이미 18번 SQL을 적용했다면 다시 실행할 필요가 없습니다.
   기존 01~17 단계가 적용되어 있는 운영 환경을 전제로 합니다.
⑤ 병선님이 커밋·푸시하여 WORKSPACE·계산기·ACADEMY 앱의 배포를 반영합니다.
   기존 Git 연결과 Streamlit Secrets는 유지합니다. 새 운영 의존성은 없습니다.
⑥ 배포 후 새로고침하고 WORKSPACE에 다시 로그인합니다.
   공개 버전: hwarang-2026.10.08-platform-v63.3-reaudit

2. 이번 전체본에 포함된 개선
- 한국어 PDF 글꼴 포함, 관리자 AI 비용 조회 오류 수정, 반복 조회 캐시 등 V63.2 개선 유지.
- 개별 계산기 새 탭 연결은 매번 새 일회용 연결을 준비합니다.
  사용한 연결 및 60초가 지난 연결은 비활성화하고 ‘연결 다시 준비’를 안내합니다.
- C07 평가 기준의 보험료는 현재 회차에서 고객이 공개한 금액과 확실성에 맞춥니다.
- 계정별 학습 이력 저장·복원, 최근 20회 목록, 누적 요약, 관리자 연동을 제공합니다.
- 완료 복기는 Streamlit 기본 다운로드 버튼으로 HTML을 저장합니다.
- 규칙 기반 잠정 평가와 정식 AI 평가를 구분하고 관리자 전체 기록을 한국 시간으로 집계합니다.
- 관리자 예산은 USD로 명확히 표시합니다.
- 계정이 바뀌면 이전 계정의 화면 상태를 제거합니다.
- 계산기 모듈 이름은 modules/calculators/hwarang_calculator_center.py입니다.
  관련 import, 화면 스타일, 입력 및 세션 키를 화랑 명칭으로 통일했습니다.

3. 파일 정리 결과
- 입력 전체본 533개 파일에서 불필요 파일 173개를 제외했습니다.
  생성 캐시 144개 / 과거 보고서·중복 안내·검사 결과 15개 / 개발 검증 산출물 14개.
- 실제 사용 중인 계산기 호환 코드, 전체 88개 계산기, ACADEMY 엔진과 데이터,
  PDF 글꼴·라이선스, 보험사 로고, Excel 템플릿, SQL 이력, 운영 스크립트를 유지했습니다.
- 재검증에 필요한 테스트 코드도 유지했습니다.
- 이전 실행 결과 파일들은 최종 검증 요약인 VERIFICATION_SUMMARY.json으로 정리했습니다.
- 브리핑 관련 45개 파일과 기존 SQL은 바꾸지 않았습니다.
  브리핑 배포 일치 검사에 필요한 STAGE1_CHANGED_FILES.json은 실행에서 사용하므로 유지했습니다.
- 정리 도구는 확인된 과거 파일의 내용 해시가 일치할 때만 삭제합니다.
  수정된 개인 문서, 알 수 없는 파일, 계정 설정, 가상환경, 저장소 연결 정보는 보존합니다.
  이전 계산기 모듈도 원본 내용 해시로 식별합니다.
- 전체 파일의 SHA-256은 FULL_PACKAGE_MANIFEST.json에서 확인할 수 있습니다.
