Web-only font, unmodified. Copyright LY Corporation; SIL Open Font License 1.1 (OFL.txt).
Official family: https://seed.line.me/index_kr.html
WOFF2 distribution: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_11-01@1.0/LINESeedKR-Bd.woff2

The workspace embeds this bundled font so it does not depend on a font CDN.
The customer reader uses the same pinned CDN file, allowed by its existing CSP.
