## 3. 최근 변경과 제외

최근 서버 변경은 브리핑 완료 보강·내부 UX·Reader 호출 오류 수정·고객 및 내부 가독성 개선에 한정한다. 종합뉴스 최대 12건·요약 3~4문장·날씨 강화·비서님 기사 자동 공급원 등록는 아직 구현하지 않았다. 홈 축소는 1.12.5-home에 반영했다. 이번 전체 ZIP은 기존 코드 통합이며 이 작업들을 몰래 포함하지 않는다.

## 4. 전체 완료 관리

향후 기능 registry/콘텐츠/운영 설정을 기준으로 세부 기능 목록을 확정하고 각 기능에 요구사항·코드·검증·운영 근거를 연결한다. 전체 진행률은 그 목록과 동일한 완료 기준으로 산정한다. 현재 전체 %는 미산정이다.

## 홈 브리핑 축소 적용 — 1.12.5-home

- Q1 사용자 승인에 따라 1.12.4-audit 수정 전체를 보존하고 홈 요약을 축소했다. 최종 로컬 준비 엔진은 1.12.5-home이다. 앞 절의 1.12.4 검수는 기반 변경 이력이다.

- 날짜 분기·빈 자료·Streamlit 렌더/버튼 이동을 로컬 확인했다. 실제 브라우저 시각 검수 및 운영 배포는 수행하지 않았다. 생성 일정·AI 요청·DB·Worker·기존 최적화를 보존했다.
