# HWARANG 1.17.0 · 세 앱 프리미엄 홈 적용 안내

## 제공 상태
- 2026-10-15 소스 적용·로컬 검수 완료. 운영 서버에는 배포하지 않았습니다.
- 업로드된 서버 통파일 1.12.7 이후, 이 대화에서 제작한 1.13~1.16 아카데미/AI 시뮬레이터 개선을 보존한 누적본입니다.
- 전체 플랫폼 빌드: `hwarang-2026.10.15-platform-v70-premium-homes`.
- 브리핑 엔진 자체의 버전과 전체 플랫폼 UI 버전은 별개입니다.

## 어떤 파일을 사용할까요?
1. `HWARANG_FULL_1.17.0_PREMIUM_HOMES.zip`: 전체 소스. 현재 저장소 전체와 대조하여 적용할 때 권장합니다.
2. `HWARANG_CHANGED_1.17.0_FROM_1.12.7.zip`: 이번에 업로드된 1.12.7 통파일 대비 누적 변경본. 이전에 받은 1.13~1.16 수정도 포함합니다. ZIP 내부 경로를 유지해 프로젝트 루트에 덮어씁니다.
3. `HWARANG_1.17.0_APPLY_GUIDE.md`: 이 안내서입니다.

전체본과 변경본을 둘 다 적용할 필요는 없습니다. 둘 중 하나를 사용하세요. 별도로 수정한 소스가 있으면 덮어쓰기 전에 비교하세요. 변경 목록과 파일별 SHA-256은 각 ZIP의 `PREMIUM_HOMES_RELEASE.json`에 있습니다.

## 적용 순서
1. 현재 GitHub 저장소를 백업하거나 현재 커밋을 기록합니다.
2. ZIP을 풀고 동일한 파일 경로로 적용합니다. Python 파일뿐 아니라 CSS·JS·JSON 자산도 함께 올려야 합니다.
3. 저장소에 커밋한 뒤 WORKSPACE / ACADEMY / CALCULATOR 세 Streamlit 앱의 변경 반영을 확인합니다. 필요하면 각 앱을 재시작합니다.
4. 브라우저를 새로고침하고 WORKSPACE에서 연결 버튼을 통해 아카데미와 계산기에 들어갑니다. 기존 인증과 일회용 연결 정책은 유지합니다.
5. 각 앱 하단 또는 기존 버전 표시에서 최신 빌드를 확인합니다. 아카데미 컴포넌트와 정적 자산 캐시 키는 1.17로 올렸습니다.

## SQL / Secrets
- 이번 홈 디자인 변경에는 새 SQL이 없습니다. 이미 적용한 23·24번 SQL은 다시 실행하지 않습니다.
- 기존 Supabase / AI API / 외부 앱 주소 Secrets를 유지합니다. 이 ZIP에는 실제 비밀키를 포함하지 않습니다.
- 기존 AI 엔진·음성 설정·비용 정책·권한과 세션 정책을 유지합니다.
- `.github/`, `modules/briefing/`, `public_reader/`, `supabase/`는 직전 1.16 작업본과 바이트 단위로 동일합니다.

## 실제 반영 범위
### WORKSPACE
- 밝은 블루의 업무 데스크, H 브랜드 헤더, 계정 표시, 보장분석 시작 영역.
- 전체 업무 도구를 두 열의 이모지 목록으로 배치하고 검색·업무 분류를 유지했습니다.
- 기존 등록 메뉴의 권한과 목적지를 보존했습니다. 브리핑 센터와 원수사 빠른 검색도 유지했습니다.
- 사이드바 메뉴에 친근한 이모지를 적용했습니다. 관리자·계정·로그아웃 메뉴는 기존 앱이 계속 관리합니다.

### ACADEMY
- 아이보리·세이지 그린, 상단 메뉴, 교육 프로그램과 자료실 중심의 홈.
- AI 상담 시뮬레이터는 상위 아카데미의 하위 기능으로 유지합니다. 아카데미 홈 / 시뮬레이터 홈 / 실제 훈련을 분리합니다.
- 자료실과 신입교육·상담교육·보험실무·시험은 기존 구현 상태에 따라 준비 중으로 표시합니다. 시안의 가상 자료와 가상 학습 기록은 운영 데이터로 넣지 않았습니다.
- 실제 저장된 상담 이어하기·기록·크레딧·음성 잔여량을 연결했습니다. 잔여량은 접힌 상태에서도 요약이 보입니다.
- 기존 규칙 기반 훈련과 이력, 시뮬레이터 5개 장면 및 AI 훈련 엔진을 보존했습니다.

### CALCULATOR
- 독립된 화이트 홈, 상단 전체/분류 메뉴. 데스크톱 사이드바를 상단 메뉴로 옮겼습니다.
- 기존 88개 계산기와 분류별 권한, 검색, 새 탭 열기, PDF/출력 경로를 유지합니다.
- 홈에서는 분류별 목록을 접고 펼칠 수 있으며 첫 분류가 열려 있습니다. 검색은 허용된 전체 목록을 대상으로 합니다.
- 보험료 합계를 홈에서 바로 계산합니다. 기본 10만원·20년은 입력 예시이며 실제 고객 정보가 아닙니다.
- ‘이 조건으로 상세 계산’을 누르면 월 보험료·전체 납입 개월을 상세 계산기로 넘깁니다. 이 동작은 해당 상세 계산기의 기존 조건을 명시적으로 바꾸며 기납입 개월은 0으로 시작합니다. 상세 화면에서 확인·수정할 수 있습니다.
- 홈에 돌아와도 빠른 계산 입력을 유지합니다. 허용되지 않은 분류의 빠른 계산은 표시하지 않습니다.

## 움직임과 반응형
- 버튼·이모지의 호버와 눌림 반응, 지원 브라우저의 메뉴/상세 열림·닫힘 전환을 적용했습니다.
- 동작 줄이기 설정을 존중하며, 지원하지 않는 브라우저에서도 펼침 기능은 즉시 동작합니다.
- 모바일에서는 콘텐츠가 세로로 정렬됩니다. WORKSPACE는 기존 Streamlit 사이드바 열기 버튼을 사용합니다.
- WORKSPACE/계산기는 실제 Streamlit 컨트롤을 사용하므로 시안과 글자 크기·간격·메뉴 펼침 방식에 일부 차이가 있습니다. 아카데미는 기존 전용 프런트엔드 안에 적용했습니다.

## 검수
- 기존 pytest 325개 통과.
- Streamlit 실제 렌더러 검사: 기존 WORKSPACE 이동 및 제한 계정, 88개 계산기 경로, 빠른 계산 결과, 상세 입력 전달, 목록 복귀 입력 유지, 검색, 계산기 권한 없는 계정.

- 운영 Supabase·유료 AI API·실제 Streamlit Cloud 배포 검수는 수행하지 않았습니다. API 호출이나 크레딧 차감 없이 검사했습니다.
