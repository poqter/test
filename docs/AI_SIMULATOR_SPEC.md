# 2026-10-14 · 1.15.0 몰입형 상담 흐름 업데이트

고객 소개 → 대화·반응 기억 → 자료/상황 변화 → 명확한 종료 → 결정적 장면 재도전으로 연결.
- 고객 소개는 공개 정보만 표시. 대화 시작 시 학습 회차 저장.
- 반응 기억은 실제 사용자/고객 대사 인용 검증 후 갱신. 상태는 단계적으로 변화.
- 자료 카드: 공유 동의 후 등장. 대화를 유지한 자료 창에서 열람.
- 가족 공동 결정/제한된 시간은 고정 고객 설정과 맥락을 따름. 상황은 되돌리기에서도 복원.
- 자유 연습의 변화 안내는 선택 사항이며 공식 평가에는 미노출. 숫자형 신뢰 점수 없음.
- 종료 후 장면 최대 2개에서 재훈련. 동일 상태 복원 후 실제 전후 답변 비교. 원본 기록 유지.
- 1.13.0/1.14.0 모두 적용 가능한 누적 변경 ZIP. SQL 23·24 이후 추가 SQL 없음.
- 전체 테스트 325개 및 UI/브라우저 흐름 확인. 실제 API 대화 품질 및 운영 배포는 아직 미검증.
