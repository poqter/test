# 화랑 플랫폼 유지 업무와 시뮬레이터 삭제 준비

2026-11-19 한국시간 기준. 운영 소스 기준은 `67fe3a382c4bc2a5b9560e763a35232c32819508`이다. 운영 DB는 함수 정의와 권한, 테이블·트리거 메타데이터를 읽었다. 운영 화면에 관한 아래 기록은 기존 검수의 결과다. 이번 변경의 교육·시험 검증에는 가상 계정과 분리 DB를 사용했다.

## 유지할 전체 업무

WORKSPACE 도구 등록 22개와 별도 앱·관리자·자동화 경로를 업무별로 묶었다. 점검 중이거나 비공개인 기능도 유지 대상에 포함한다.

**삭제 예정**은 AI 상담 시뮬레이터와 그 전용 상담 이력·공식 평가·음성 처리, Credit·Voice 자산 기능이다. 보험시험의 채점·오답 기록, 신입교육의 고객 미션·실습 평가·관리자 피드백은 유지한다. 삭제 예정 서비스의 행 데이터 삭제·보존 기간은 이 작업에서 실행하거나 확정하지 않았다.

## 삭제 시 유지할 연결

- **교육 화면**. 교육·CBT 진입보다 먼저 시나리오를 검증하거나 잔액을 조회하던 경로를 분리했다. 시뮬레이터 패키지가 빠진 상태에서는 예전 상담 권한이 남았어도 교육 홈·메뉴에 상담 경로가 나타나지 않는다. 과거 상담 링크·화면 상태는 교육 홈으로 돌아간다. 배포 상태 확인도 음성 모듈 없이 동작한다.
- **시험·교육 데이터**. 운영의 시험 RPC 1개와 교육 RPC 8개에서 이름으로 추적되는 내부 함수 본문을 대조했다. 이 범위에서 시뮬레이터·잔액 직접 참조는 발견되지 않았다. 시험 문제·응시, 교육 자료·프로필·진도·제출·검토와 공통 소속·권한 도우미는 보존한다. 정적 대조만으로 동적 SQL이나 모든 외부 호출까지 검증했다고 보지 않는다.
- **신규 가입**. 운영의 `profiles` 생성 트리거 중 `on_profile_created_ai_credit_account`와 `on_profile_created_voice_account`는 현재 활성 상태이며 삭제 대상 자산 테이블을 사용한다. 실제 삭제 시 이 두 트리거를 먼저 해제한다. `on_profile_created_app_access`와 `on_profile_created_learning_profile`은 유지한다. 격리 DB에서 두 자산 트리거를 제거하고 두 자산 계정 테이블명을 바꾼 뒤 신규 프로필에 기본 앱 접근·교육 프로필이 생성되는지 확인한다.
- **관리자센터**. 공통 관리자 화면에는 자산 모듈을 불러오는 코드와 AI 운영 집계가 남아 있다. `hwarang_admin_user_operations_view`, `hwarang_admin_ai_usage_daily_view`도 자산·시뮬레이터 관련 참조를 포함한다. 전체 삭제 전 일반 계정·권한 화면과 운영 점검의 호출을 분리한 뒤 의존 객체를 정리해야 한다. `profiles_admin_view`는 별도 객체다.
- **자동검사**. 신입 과정의 DB 검사는 유지할 CBT의 격리 DB 패키지를 사용한다. 자산 계정이 없는 조건에서도 과정의 평가·제출·검토가 동작하는지 그 검사에서 확인한다. 기적용 마이그레이션은 이력으로 보존한다. 실제 삭제 때에는 후속 마이그레이션을 별도로 검증해야 한다.
