# 화랑 WORKSPACE 공식 UI·UX 기준
확정일: 2026-10-27 · 적용 범위: WORKSPACE, 계산기, ACADEMY, 관리자 및 고객 공유 화면

사용자 편의를 최우선으로 한다. 중요한 정보부터, 적은 입력으로, 예측 가능한 조작과 정확한 저장 상태를 제공한다.

## 공통 화면
입력·결과형 / 단계별 작업형 / 조회·상세형을 작업에 따라 선택한다. 제목과 목적 한 문장, 핵심 행동을 먼저 배치한다. 고급 설정과 진단 정보는 접는다. PC 입력은 기본 2열 이내, 모바일 1열. 본문 16px, 긴 읽기 18px 수준, 충분한 줄 간격. 표는 핵심 열만 노출하고 상세로 연결한다.

## 버튼·이동
영역별 주요 행동 하나만 강조한다. 계산하기/변경사항 저장/PDF 다운로드처럼 동작과 대상을 명시한다. 검색어 지우기와 입력값 초기화를 구분한다. 삭제·덮어쓰기에는 영향에 비례한 확인을 둔다. 처리 중 중복 실행 방지, 실패 시 재시도. 목록 복귀 시 검색·필터·페이지·위치를 보존한다. 터치 목표 44px 이상, 키보드 초점 표시, 색상 외 문자·기호로 상태 구분.

## 입력·저장
필수/선택, 금액·기간 단위를 명시한다. 빈칸/0/알 수 없음을 구분한다. 예시는 사용자가 요청할 때만 적용한다. 오류는 입력란 가까이 수정 방법과 함께 표시한다. 입력이 바뀌면 이전 결과에 재계산 필요 상태를 표시한다. 서버 저장과 세션 보관은 구분한다. 응답을 확인하기 전 저장 완료로 표시하지 않는다. 자동 외부 고객정보 저장 범위를 확대하지 않는다.

## 안정성·출력
주기적 갱신은 문제·스크롤·초점을 재생성하지 않는다. 최신 입력과 결과·다운로드 파일의 일치 여부를 확인한다. 공유는 고객용 미리보기를 제공한다. 빈 결과/로딩/권한/연결 오류를 구분한다.

## 1순위 실제 수정 범위
1. CBT 전용 컴포넌트: 브라우저 초 단위 타이머, 서버 마감 유지, 답안 순차 저장·재시도·충돌 복구, 확인 후 제출.
2. 기존 기록 호환: 스냅샷 불변, 기존 번호/답안/마감 유지. 신규 랜덤만 중복 제거·미응시 우선 적용.
3. 결과·복습: 과목별 점수, 원문 오답, 정답 확인 이후 해설, 별도 복습 기록.
4. 관리자: 최근 30일, 권한 내 조직, 최신 모의시험 과목별 합격률, 미참여/기준 미달 필터, 개인 이력.
5. 다른 기능의 입력 유실·오래된 결과·오류 복구는 후속 작업이며 이번 구현 완료로 간주하지 않는다.

## 배포 검수
기존 시험 복원·시간 종료·빠른 선택·재전송·중복 제출·권한·원문 동일성·모바일 폭·키보드·글자 확대를 검증한다. 진행 중 응시 여부 확인 후 배포한다. 전체 기능은 기능별 검수표를 완료하기 전 전수 검수 완료로 표시하지 않는다.
