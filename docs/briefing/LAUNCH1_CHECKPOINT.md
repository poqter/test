## 확정 기준 유지

- 종합: 전날/당일 아침 이슈 최대 10개, 대표 최대 1개 포함, 기사 원문 링크와 짧은 요약.
- 경제: 정확한 6개 지표, 실제 수집 뉴스/관측 기반 전체 흐름 3~5문장, 기사 총 6~8개, 필요한 기사별 해설/영향.
- 보험: 내부 업계 소식과 상담 활용; 대표 UI 최대 1개. 기존 CORE 8/LIGHT 포함 총 15 한도는 할당량이 아님. 고객은 승인된 생활 관련 정보만.
- 발신자: 생성 계정의 등록 이름+실제 직함. 간결한 미리보기와 본문/PDF 일치, 링크 생성 시 고정.
- 고객: 로그인 없이 읽기, 큰 글자, 출처 링크, PDF. 직원 메뉴·상담 문구·운영 로그·비용·키는 제외.
- 조직 단위 최초 승인, 영역별 3영업일 관찰, 한국 공휴일 제외. 최소 기사 2건은 정상 판정의 안전 하한이며 목표 기사 수를 줄이는 변경이 아님.

## 이번 구현 결정

서버 OG는 Cloudflare Worker + 기존 Supabase RPC/비공개 Storage로 구현한다. Streamlit의 다운로드 HTML과 실제 카카오가 읽는 HTTP 응답을 구분한다. 코드와 설정은 `public_reader`에 있다. 새 유료 도메인/정적 이미지 API/AI 이미지 생성은 사용하지 않는다.

신문 RSS를 기본 경로로 추가하고 기존 기관 설정은 보강 자료로 유지한다. 한 발행사가 분석 후보를 독점하지 않도록 후보를 분산한다. 날짜/중복/목록 검수와 실제 표시 본문의 품질 기준을 유지한다.

경제 Provider는 FMP/Treasury와 선택 ECOS 어댑터를 구현했다. API 키·실제 지수 지원·고객 표시 계약을 연결했다고 주장하지 않는다. 승인된 JSON/FILE/URL도 유지한다. 명세의 USD_KRW는 기존 내부 코드 USDKRW에 매핑한다. 저장된 `market_flow`/`market_flow_facts`는 전체 해설/근거 참조를 담는다. 증권사 리서치 종합은 선택 기능이며 `BRIEFING_ENABLE_RESEARCH=true`로 켤 수 있다.

문구 정정은 근거 URL·지표를 바꾸지 않고 새 Revision/Snapshot으로 저장한다. 같은 공유 토큰의 본문/PDF를 갱신하며 원래 발신자를 유지한다. 지표/출처 자체의 교체는 검증된 새 입력과 새 판본 생성 절차로 처리하고 임의 문구 수정으로 우회하지 않는다.

전체 AI OFF와 브리핑 예약 생성 OFF를 모두 구현했다. 신규 조직 정책은 자동 생성/자동 공개/고객 공유를 기본 OFF로 둔다. 사용자 1회 유료 검수 허용을 일일 자동 생성 비용 허용으로 해석하지 않는다.

## 검수·출시 게이트

자동 회귀/통합/보안 검사와 가상 자료의 전체 PDF 페이지 검수는 Codex가 완료한다. DB 실적용·메일 수신/실제 비밀번호·공급원 계약·실제 휴대폰/카카오 캐시는 본인/운영 환경 확인이 필요하다. 자동 수집 실제 관측과 영역별 정상 3영업일 결과까지 확인해야 정식 출시 조건이 충족된다.

유료 검수 허용: 사용자 2026-10-09 메시지 “비용이 발생할 수 있는 부분은 1회 허용하도록 할게”. 사용 상태: **미사용**, 실제 OpenAI 호출 0회. 새 버전 적용과 무료 연결 검사 후 기존 API로 1회 검수한다. 추가 유료 재시도나 신규 구독은 포함하지 않는다.

현재 적용 자료: 루트의 `HWARANG_LAUNCH1_APPLY_20261009.md`, `HWARANG_LAUNCH1_REVIEW_20261009.md`, `LAUNCH1_MANIFEST.json`. 기존 5개 명세는 설계 기준으로 유지하고 이 문서를 최신 구현 기록으로 사용한다.
