## 1. 구성

**지표 6개 → 전체 흐름 3~5문장 → 기사 총 6~8건 → 필요한 기사별 해설**.

대표 최대 1개는 기사 총 6~8건에 포함한다. 지표·전체 해설은 기사 수가 아니다. 적격 기사 부족 시 실제 수량 표시. 대표 UI와 기존 CORE 분류를 혼동하지 않는다.

해설은 실제 수집 뉴스·관측값을 사용하며 고정 일반론 반복·첫 기사 설명의 전체 해설 복제는 하지 않는다.

## 3. 데이터 계약·계산

필수: metric_code/label/value/unit, as_of/market_timezone/retrieved_at, source_name/url/provider, data_type/reference_definition, previous_value/as_of, change_value/unit, data_status, 이용·외부 표시 권한 근거.

data_type: official_close/previous_close/official_daily/delayed/realtime.
data_status: ok/previous_confirmed/unavailable/conflicted.

Python으로 계산: 지수 (현재-직전)/직전×100, 환율 차 원, 금리 차 %p. 1%p=100bp. 같은 지표/정의/Provider의 직전 값과 비교한다. 기준 변경 후 서로 다른 시계열 변화를 만들지 않는다. AI는 값·변화를 추정하지 않는다.

## 4. 거래일·휴장·누락

뉴스 구간은 **전날 00:00 KST부터 해당 생성의 수집 마감까지**. MARKET 마감 목표 07:00 / 공개 07:30. 지표는 뉴스 구간과 별개로 마지막 확인 거래일/관측일이다.

한국/미국 거래일·휴장·서머타임 각각 처리. 카드마다 실제 기준시각 표시. 휴장에는 마지막 확인값과 실제 날짜·마지막 두 관측일 변화. 장중 최고·기사 잠정값을 종가로 바꾸지 않는다.

누락 “확인 중”, 0·과거값 오늘 재라벨·모델 추정 금지. 정상 갱신주기보다 오래된 값은 이전 관측 표시하고 임의 승인하지 않는다. 필수 6개를 충족하지 못하면 MARKET partial, 정상 외부 공개 차단. 내부 기사 읽기는 가능하다.

개인/내부 전용 유료 플랜을 고객 표시용으로 구매하지 않는다. Provider Adapter로 화면·프롬프트와 분리한다. 6개 지표 지원/시간/표시 권한/총 견적/해지조건을 Codex가 비교한 뒤 사용자가 신청·요금만 결정한다.

**Provider·표시 계약비는 미확정**이다. 0원 또는 전체 서비스 월 $3~10으로 약속하지 않는다. 확인 중에도 Fixture로 계산·화면·해설·공유 구현 가능. 비용 상세는 BRIEFING_RELEASE_ROADMAP.md.

## 6. 경제 기사

국내외 증시·금리/채권·환율·물가/고용·대출/가계·기업/산업·통상/원자재 등 실제 당일 뉴스. 종합·경제·국제 언론 활용, 공식 발표는 확인 근거. 기관 자료만 목록을 채우지 않는다.

같은 Shared Event/RSS/검색 경로 재사용. 사건 단위 총 6~8 목표. 제목·1~2문장·발행사/일자·원문 기본 표시. 기사 속 원인 설명은 “보도에서는 …로 설명”과 관측 등락 사실을 구분한다.

## 7. 전체 흐름과 기사별 해설

전체 저장 필드: flow_headline, flow_commentary(3~5문장), metric/Event/Source fact_refs, 관측/해석/관찰점의 구분.

전체 해설 순서: 확인된 움직임 → 뉴스의 배경과 한계 → 관련 생활/금융 영향 → 조건부 평가·다음 관찰점. 여러 지표가 다른 방향이면 차이를 설명한다. 금리 변화가 모든 대출·보험료에 즉시 반영된다고 단정하지 않는다. 근거 부족 시 사실 중심 축약.

| 기사별 단계 | 표시 |
|---|---|
| 사실 1~2문장 | 기본 |
| 의미·용어·배경 | 필요한 기사 펼침 |
| 영향 | 근거 있는 대상·방향·조건 |
| 평가 | 확인 범위·불확실성·다음 확인 |
| 출처 | 실제 URL·발행사/일자·추가 근거 |

차입자·예금자·해외 지출·사업자 영향 차이가 있으면 구분한다. 대상군 확대·매수매도 추천·수익 보장·공포·모델 수치 생성 금지. 모든 기사에 장문 영향·상담을 강제하지 않는다. 해설은 저장하고 읽기/펼치기 시 AI 재호출 없음.

## 8. UI·내외부

모바일 지표 2열×3행 우선 검토, 좁은 화면/큰 글자에서는 재배치. 숫자·단위·변화·각 기준일, 등락 색+부호/텍스트. 지표 바로 아래 전체 해설, 대표 최대 1개와 짧은 기사 목록.

고객은 지표/해설/뉴스, 설계사는 필요한 상담 대상·조건·관련 도구 추가. 고객 점수·시장 온도·내부 확신도·비용·전략은 숨긴다. 실시간 refresh·복잡한 차트·컨센서스 일정은 후속이다.
