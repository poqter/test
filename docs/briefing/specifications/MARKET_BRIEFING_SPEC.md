# 경제·금융 브리핑 — 1.11.0-release

2026-10-13 / Asia/Seoul. 사용자 확정에 따라 이전 V1.8 지표 필수 조건을 대체한다.

- 목적: 확인된 경제·금융 기사로 오늘의 흐름과 생활·금융 영향을 쉽게 이해한다.
- 지표 6개 대시보드 및 별도 시장 데이터 공급원 의존을 제거한다. 미설정이 생성·게시·공유를 막지 않는다.
- 전체 흐름 3~5문장 목표, 근거 부족 시 짧게. 각 문장은 실제 분석 사건에 연결된 근거를 사용한다.
- 정규 기사 최대 8개(6~8 목표), 대표 최대 1개 포함. 부족하면 적격 실제 수량. 기사 수를 채우는 추정/과거 기사 사용 금지.
- 기사 제목·1~2문장 요약·출처/실제 게시일/원문 링크·필요한 배경과 영향 기본 노출.
- 기사 속 금리·환율·지수 수치는 확인된 기사 근거와 날짜에 한정. 별도 실시간 지표·등락 계산·ETF 대체 없음.
- 수집 구간 전날 00:00 KST~07:00, 공개 목표 07:30. 예약 실행 지연 시 늦게 게시할 수 있으며 정시 도달을 보장하지 않는다.
- 매일 운영, 주말/휴일도 적격 기사를 사용. 중요한 공식 발표는 당일 관리자 추가 업데이트 경로 제공.
- 근거·본문 자동 확인을 통과하면 게시. 실패 시 자동 복구 최대 1회, 최근 정상본 유지 및 실제 날짜 표시.
- 최초 조직 운영 승인과 기존 3영업일 자동 관찰 Gate 유지. 사용자의 일일 수동 검수는 필요하지 않다.
- 같은 날짜 NEWS 및 고객 적격 INSURANCE와 통합 공유. 내부 상담/점수/계정 ID/비용 제외.
- 모든 구성요소가 게시·검증·공유 허용인 경우만 외부 링크 제공. 하나라도 비공개/회수되면 전체 링크 차단.
- 이름·실제 직책은 서버의 계정/직책 정보에서 조회. HTML·OG·PDF 모두 동일.
- 정정은 새 immutable Snapshot/Revision. 기존 공유 링크는 최신 정정 본문·PDF로 갱신, 이미 저장한 PDF는 변경되지 않는다.
- 별도 유료 데이터 구독 불필요. 조회·공유·PDF·정정에는 AI 호출 없음. 신규 수집/분석에는 기존 API 비용 발생 가능.
- 공급원 모듈은 이전 코드 호환을 위해 보존하되 현 운영에서는 호출하지 않는다.
