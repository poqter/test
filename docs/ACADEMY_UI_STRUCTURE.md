# HWARANG ACADEMY 1.16.0 · 두 홈 UI/UX 개편

2026-10-14 / 소스 제작·로컬 검수 완료. 운영 서버 배포는 하지 않았습니다.

## 이번 버전의 범위
ACADEMY는 전체 교육을 제공하는 상위 앱입니다. AI 상담 시뮬레이터는 그 안에 있는 하나의 기능입니다.

- 아카데미 홈: 전체 교육 프로그램, 나의 학습, 남은 이용량을 구분했습니다. 신입교육·상담교육·보험실무·시험/평가·교육자료실은 기존처럼 준비 중으로 표시합니다. 새 교육 기능을 구현했다고 표시하지 않습니다.
- 시뮬레이터 홈: 전화로 약속 잡기, 첫 상담, 보장분석 설명, 가입 제안, 거절 대응을 선택합니다. 자유 연습/공식 평가 안내와 상담 이어하기·기록 접근을 제공합니다.
- 훈련 설정: 난이도, 고객, 텍스트/음성/혼합 등을 선택하는 별도 단계입니다. 장면 선택만으로 AI 호출이나 크레딧 차감이 발생하지 않습니다.
- 데스크톱에서 이용량은 우측 보조 영역에 배치했습니다. 모바일은 교육/훈련 콘텐츠 아래로 정렬합니다.
- 직접 시뮬레이터 링크로 들어가도 시뮬레이터 홈부터 시작합니다. 훈련 화면에 시뮬레이터 홈/ACADEMY 홈 버튼을 따로 두었습니다.
- 설정 연결이 실패해도 돌아가기 버튼은 먼저 표시합니다.
- 계정이 바뀌면 이전 계정의 홈/시뮬레이터 화면 상태를 초기화합니다.
- 기존 규칙 기반 훈련과 기록, AI 상담 엔진·평가·음성 기능은 유지했습니다.
