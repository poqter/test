## 구현
공식 UI·UX 기준을 docs/UI_UX_STANDARD.md에 기록했다.
- 브라우저 내 초 단위 타이머, 변경 없는 문제 DOM 유지, 20초 서버 동기화.
- 답안 순차 저장, 응답 유실 재시도, 충돌 시 명시적 복구, 종료 확인.
- 원문 문제 기반 랜덤 출제: 공통 문항의 과목 소속과 배점 유지, 공백·줄바꿈 중복 비교, 정답/해설 충돌 제외, 미응시 우선.
- 기존 스냅샷·답안·마감 유지. 새 복습 기록은 부모 시험과 분리하고 정답 확인 후 해설 공개.
- 결과 및 오답 한 문제씩 복습, 과목별 결과·소요시간.
- 관리자 날짜·조직 필터, 과목별 개인 최신 모의시험 합격률, 미참여·기준 미달 필터, 조직 비교, 개인 이력.

## 검증
- 기존 36회차 × 3과목 조합 108개 회귀 + 신규 랜덤/복습/권한/원문 동일성 검증. 실제 문제은행을 이용한 개발 DB 테스트 1,824개 통과.
- 저장소에는 원본 PDF 문제를 복제하지 않고 합성 문제 fixture를 사용한다. 재현 가능한 DB 테스트 1,826개 통과(공백·줄바꿈/금액 차이 비교 포함).
- JS DOM 동작 검증 36개: 타이머/DOM 유지/연속 선택/폴링 중 선택/재시도/충돌 복구/제출 확인/시간 종료/복습 공개 시점.
- Python 5개: 저장 응답 유실/동시 수정/서버 종료 우선/KST 날짜/최신 모의시험 집계.
- Streamlit AppTest: 선택→컴포넌트 표시→결과→복습, 관리자→개인→결과→목록 복귀 통과.
- Python 컴파일 및 git diff --check 통과.

## 남은 검수
- 모바일 실화면 검수 미완료: 제공된 클라우드 브라우저는 뷰포트 변경 API를 제공하지 않으며 확대 단축키도 화면 크기를 바꾸지 않았다. 로컬 파일 URL 접근은 브라우저 정책상 제한됨. 다른 수단으로 우회하지 않았다.
- 반응형 CSS와 DOM 검증은 구현되어 있으나 320/390px 실브라우저 및 실제 iOS/Android 터치 검수를 대체하지 않는다. 모바일 검수 완료로 보고하지 않는다.
- 후속 검수 시 진행 중인 실제 시험을 변경하거나 제출하지 말 것. 이미 사용된 검수 기록 및 그 자식 복습도 일괄 삭제하지 말 것.

## 범위와 한계
이 개편은 WORKSPACE 전체 UI 변경 완료를 뜻하지 않는다. 다른 계산기·상담 문서의 입력 유실 및 재계산 상태 개선은 후속 작업이다.
관리자 집계는 서버가 허용하는 최신 10,000건 이내다. 한도 도달 시 일부 집계임을 화면에 경고한다. 과거의 모든 개별 활동 로그가 아닌 완료/최종 저장 시점을 참여 기준으로 사용한다.
