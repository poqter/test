# 화랑 ACADEMY 1.15.0 — 몰입형 상담 흐름

## 적용 범위와 상태

1.14.0의 역할 분리·종료 처리·홈/채팅 개편에 아래 여섯 기능을 추가했습니다. 이번 변경 ZIP은 1.13.0 대비 누적본이므로 1.13.0 또는 1.14.0에 적용할 수 있습니다. 운영 서버에 직접 배포하지 않았으며 실제 유료 모델 호출은 실행하지 않았습니다.

## 적용 순서

1. 진행 중인 상담을 마무리하거나 저장한 후 CHANGED ZIP을 저장소의 같은 경로에 덮어씁니다. FULL ZIP은 전체 보관본입니다. 파일 삭제는 없습니다.
2. SQL 23·24가 적용됐다면 추가 SQL 실행은 없습니다. 기존 Supabase·OPENAI_API_KEY Secrets와 이용 권한을 유지합니다.
3. ACADEMY 배포 갱신 후 새로고침하고 WORKSPACE에서 다시 들어갑니다.
4. 홈 → 첫 상담 → 고객 만나기 → 고객 소개 → 대화 시작으로 새 회차를 시작합니다. 이전 상담도 조회 가능하며 새 필드는 기본값으로 처리합니다.
5. 롤백하려면 기존 1.13.0/1.14.0 전체 ZIP의 동일 파일로 복원합니다. 새 모듈·테스트 파일은 이전 버전에서 호출하지 않습니다. DB·원장 정책은 변경하지 않았습니다.

## 여섯 가지 추가 기능

### 1. 만남의 시작

설정 다음에 고객 소개 화면이 나옵니다. 이름·나이·직업·소개 경위·처음 알려진 내용과 이번 목표를 보여줍니다. 숨은 고민·태도·시간 제약은 노출하지 않습니다. 소개를 확인하고 대화를 시작하기 전에는 학습 회차를 DB에 만들거나 고객 API를 호출하지 않습니다.

### 2. 누적되는 고객 반응

고객 응답과 함께 내부 반응 상태를 같은 API 요청에서 받습니다. 사용자 발화와 고객 답변의 정확한 인용이 검증돼야 기억으로 남습니다. 마음을 여는 정도와 부담은 한 번에 한 단계씩만 변하고, 다음 응답에 이전 대화 기억이 전달됩니다. 별도 유료 반응 판정 호출은 없습니다. 문맥 토큰이 늘 수 있으므로 실제 API 비용이 동일하다는 의미는 아닙니다.

자유 연습에서 ‘대화 변화 안내 보기’를 켜면 관찰된 대사와 변화만 표시합니다. 기본은 꺼짐이며 공식 평가에서는 표시하지 않습니다. 신뢰 점수·숨은 고객 설정·추측한 속마음은 보여주지 않습니다. 인용 검증은 의미 해석의 완전한 정확성을 보장하지 않습니다.

### 3. 채팅 속 보험 자료

증권을 요청하고 고객이 공유에 동의하면 해당 답변 아래 자료 카드가 등장합니다. 클릭하면 대화를 유지한 채 자료 창에서 가상 계약·보험료·보장 내용을 확인합니다. 단순 보유 질문이나 거절·나중에 공유하겠다는 말은 공개로 처리하지 않습니다. 보장분석·가입 제안 장면은 시작부터 제공 자료 카드를 표시합니다.

### 4. 의미 있는 상황 변화

고객의 실제 생성 설정이 배우자 공동 결정일 때 가족 상의 상황을 사용할 수 있습니다. 일부 표준·심화 고객에게는 시간 여유가 적은 상황이 고정 배정됩니다. 맥락에 맞을 때만 등장하며 한 번 드러난 상황은 다시 새 사건처럼 주입하지 않습니다. 완료/종료를 방해하기 위한 돌발 상황은 지침에서 금지합니다. 기초 고객에게는 추가 시간 압박을 배정하지 않습니다.

### 5. 분명한 종료

약속 확정, 고객 종료, 사용자 종료, 대화 한도 등의 결과에 맞춰 마무리 문구와 고객의 마지막 답변을 보여줍니다. 확정되지 않은 다음 일정을 만들지 않습니다. 전체 상담에서는 다음 장면으로 이동할 때 고객의 사실과 대화 기억을 유지합니다. 상담 종료와 교육 과정의 완성도 평가는 분리합니다.

### 6. 결정적 장면 재도전

종료 화면에서 관찰된 변화나 피드백의 근거에 해당하는 장면을 최대 두 개 보여줍니다. ‘이 장면 다시 연습’을 누르면 동일 고객·동일 시점의 상태로 새 비공개 자유 연습을 만듭니다. 원래 기록은 유지합니다. 다시 답한 후 이전/이번 설계사 답변과 고객 반응을 비교합니다. 한 번의 다른 반응을 실력 향상이나 인과관계의 증명으로 판정하지 않습니다.

되돌리기와 재훈련은 공개된 자료·반응 기억·상황 발생 내역도 함께 복원합니다. 이미 사용한 크레딧·음성은 되돌리지 않습니다.

## 유지되는 정책

- 자유 연습 상세는 비공개, 선택 공유·미리보기·철회 유지.
- 공식 평가는 실시간 도움 없이 진행. 종료 후 본인 재훈련은 별도 자유 연습.
- 기존 크레딧·음성 원장, 중복 호출 방지, 모델 설정 유지.
- 자동 연속 음성 전송과 미검증 총점/합격선은 계속 보류.
- 브리핑·공개 리더·GitHub 워크플로·SQL은 이번 변경 대상에서 제외.

## 검증

- 전체 Python 테스트 325개 통과. 이번 몰입 기능에 관한 테스트 21개 포함.
- Streamlit AppTest: 고객 소개→대화→증권 카드→선택적 반응 안내→종료→재도전→비교, 공식 평가 도움 제한, 음성/텍스트 전환 확인.
- Chromium: 데스크톱 1440px/모바일 390px에서 소개·자료 창·채팅·종료·재도전 비교 흐름 확인. 모바일 가로 넘침 없음.
- 검증용 고객 응답·DB를 사용했습니다. 실제 모델의 자연스러움·사실 일관성·상황 발생의 적절성, 실제 기기 음성 지연은 배포 후 검증이 남아 있습니다.

재현 명령:

```bash
python -m pytest -q
python tests/studio_ui/check.py
```

배포 후에는 새 자유 연습·텍스트 회차에서 증권 요청, 고객 부담 질문, 일정 합의, 종료, 장면 재도전을 차례로 확인하세요. 실제 응답 생성과 피드백·음성에는 기존 이용량 정책이 적용됩니다.
