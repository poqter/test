# 2026-11-06 적용 범위

- 모바일 전용 화면: 상단 여백 축소, 메뉴/알림 아이콘, 요약 카드 제거, 직원 조회 팝오버, 보기 방식 선택 메뉴, 주말/색상 안내 접기, 우측 아래 일정 등록. 주말 제외 기본값 유지.
- 공통 일정 삭제: 본인 일정, 확인 후 달력/집계 제외, 30일 개별 복구. 계약/후속 활동/피드백 및 기존 데이터 보존. 물리 삭제 자동화 없음.
- 반복 일정: 새 반복 등록에 series_id 부여. 이번 일정 또는 해당 날짜 이후의 같은 묶음 삭제. 과거 일정은 묶음 정보가 없어 임의 추정하지 않고 개별 삭제.
- 자동 갱신: 사용자 권한과 기간/지점에 묶인 변경 번호를 15~18초 간격으로 확인. 변화가 있을 때만 캘린더 fragment 조회. 본인 저장은 즉시 알림. 숨김/오프라인 대기, 재연결 재확인, 오류 시 지수형 간격 증가.
- 화면 안정성: 날짜/일정 DOM 재사용, 동일 응답 무갱신, 선택 날짜/필터 보존. WORKSPACE 도구 입력은 활성 도구 fragment로 제한하고 공통 진입 애니메이션/재실행 흐림 제거. 로그인/권한/메뉴 전환 등 필요한 전체 재실행은 유지.
- 저장 안정성: UUID로 재시도 중복 방지, 반복 등록 단일 트랜잭션, 저장 내용 재확인, 기존 revision 충돌 차단, 삭제된 일정 편집 차단, 입력 보존.

검증: Python 회귀, 실제 브라우저 합성 데이터 UI, PGlite SQL 권한/원자성/삭제/복구/버전 검사. 1,000건 독립 등록과 재전송 중복 검증은 합성 검사이며 실제 1,000명 동시 접속 부하 시험은 아님. 모든 구형 모듈의 실제 계정 입력 동작 검수는 별도 운영 확인이 필요함.
