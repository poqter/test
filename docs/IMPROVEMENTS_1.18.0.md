전체 플랫폼 빌드: `hwarang-2026.10.15-platform-v71-consultation-room`
브리핑 엔진: `1.12.8-analysis-wait`

- `HWARANG_FULL_1.18.0.zip`: 전체 프로젝트. 이전 1.13~1.17 개선을 포함합니다.
- `HWARANG_CHANGED_1.18.0_FROM_1.17.0.zip`: 직전 제공한 1.17.0 전체본 대비 변경 파일만 포함합니다. 1.17.0 적용 상태에서 사용하세요.
- 두 ZIP을 모두 적용할 필요는 없습니다. 현재 소스를 백업하고, 로컬에서 별도로 바꾼 내용과 대조한 뒤 하나를 선택하세요.
- ZIP 안의 경로를 그대로 유지해 프로젝트 루트에 적용합니다. 새 `hwarang_academy/studio/chat_frontend/` 폴더와 CSS·JS 파일, `STAGE1_CHANGED_FILES.json`, `.github/workflows/hwarang_daily_briefing.yml`도 포함해야 합니다.
- 변경 사항을 저장소에 올리고 세 Streamlit 앱의 반영을 확인하세요. 필요하면 재시작하고 브라우저를 새로고침하세요.
- 추가 SQL은 없습니다. 기존 23·24번 SQL을 다시 실행할 필요는 없습니다. 기존 Secrets는 유지합니다.

## 요청 사항별 변경
1. WORKSPACE 원수사 포털 빠른 검색을 브랜드 헤더 바로 아래, 인사말과 주요 콘텐츠보다 위로 이동했습니다.
2. 메인 메뉴 검색을 제거하고 사이드바의 기능 빠른 검색을 유지했습니다. 원수사 검색과 메뉴 검색은 별개입니다.
3. 경제·금융 브리핑의 분석 응답 대기 시간을 기본 60초에서 180초로 늘렸습니다. 연결은 10초, 읽기는 설정값을 사용합니다. GitHub Actions 변수 `BRIEFING_ANALYSIS_TIMEOUT_SECONDS`로 30~300초 범위에서 조절할 수 있으며, 미설정 시 180초입니다. 진단에 적용 대기 시간도 남깁니다. 자동 유료 재시도는 추가하지 않았습니다. 게시물 없는 관리자 화면에 실패 원인 확인 경로를 추가했습니다.
4. 아카데미 홈의 ‘복기 HTML 저장’ 노출을 제거했습니다. 기존 규칙 기반 훈련의 결과 화면에서만 나타납니다.
5. AI 상담을 왼쪽 고객 정보 / 가운데 메신저형 대화 / 오른쪽 도움·상담 관리로 재구성했습니다. 입력창과 대화 목록을 같은 컴포넌트 안에 두어 전송 중 문장이 화면 밖에 별도로 나타나지 않습니다. Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 전송 방지, 응답 대기 표시, 실패 문장 수정·재전송을 지원합니다. 공식 평가에는 힌트·되돌리기를 제공하지 않습니다. 사용자에게 공개할 수 있는 고객 정보만 프런트엔드에 전달합니다.
6. 아카데미 홈에 왼쪽 탐색 메뉴를 복원했고 계산기 센터에는 Streamlit 사이드바를 복원했습니다. 아카데미는 상위 앱이며 시뮬레이터는 그 안의 기능입니다. 교육·자료실의 기존 준비 중 상태를 임의로 운영 데이터처럼 채우지 않았습니다.
7. 계산기 홈의 오른쪽 보험료 합계 계산기를 제거했습니다. 기존 88개 계산기와 ‘현재 탭에서 열기 / 새 탭에서 열기’ 경로를 유지합니다.

## 채팅 오류의 처리 범위
- 공급자가 완료/불완전/실패 등 종료 상태로 응답했지만 응답 형식·내용을 사용할 수 없는 경우: 실패 문장은 대화·평가에 반영하지 않고 예약한 학습 크레딧을 해제합니다. 사용량과 공급자 응답 ID는 기록하며 실제 API 비용은 미확인으로 남깁니다. 사용자가 명시적으로 다시 보내거나 문장을 수정할 수 있습니다.
- 타임아웃 등 실제 처리 여부를 확인할 수 없는 경우: 중복 호출 방지를 위해 보류합니다. 자동으로 재전송하거나 무료라고 단정하지 않습니다. 홈 이동과 상태 다시 불러오기는 가능합니다.
- 이전 버전에서 이미 ‘확인 대기’로 남은 요청은 이번 파일을 적용해도 자동 해제되지 않습니다. 관리자 센터 → AI 상담 요청 확인 · 비용 미확인에서 공급자 기록과 대조해 처리 상태를 확정한 뒤 해제하세요. 이후 ‘저장 상태 다시 불러오기’를 눌러 계속할 수 있습니다.
- 음성 인식·음성 합성은 기존 경로를 유지했습니다. 이번 말풍선 즉시 표시 검증은 텍스트 입력 기준입니다. 음성 인식 문장은 기존 확인 영역에서 확인 후 제출합니다.

## 경제·금융 브리핑의 실제 진단과 남은 확인
2026-10-14 실행 기록에서 MARKET 생성 실패 후 blocked 및 게시할 snapshot 없음이 확인되었습니다. 제공된 진단에는 분석 단계 ReadTimeout, 사용량 미확인이 기록되어 있습니다. 따라서 화면 변경만으로 해결되는 문제가 아닙니다.
확인한 실행: https://github.com/poqter/test/actions/runs/38493439621 및 https://github.com/poqter/test/actions/runs/38497921895
이 실행들은 1.12.5-home 엔진을 사용했습니다. 이번 소스의 1.12.8 보완은 향후 분석 요청의 대기 시간을 늘리는 조치이며 성공을 보장하는 수정은 아닙니다.
기존 보류 건은 공급자 사용 기록을 확인한 뒤 브리핑 운영 관리의 기존 복구 절차를 사용해야 합니다. 무조건 재생성하거나 잠금을 삭제하지 마세요. 배포 후 다음 실행의 MARKET snapshot 생성 및 실제 게시 여부를 확인해야 합니다. 이 작업에서 운영 데이터나 보류 상태는 변경하지 않았습니다.
